  3. macOS用户：从官网下载.dmg文件，将Clash图标拖入“应用程序”文件夹即可。

第二步：配置订阅节点——给Clash“喂”进代理资源

Clash本身不生产节点，它只是节点的“搬运工”。你需要从服务商处购买或免费获取订阅链接（通常以URL形式提供）。

  1. 获取订阅链接
    在服务商网站注册账号、购买套餐后，他们会在用户中心提供一个“订阅链接”。复制这个链接，它就像一把钥匙，能自动导入所有节点信息。

  2. 导入配置文件
    打开Clash客户端，点击左侧的“配置”（Profiles）标签，将复制的订阅链接粘贴到输入框中，点击“下载”。Clash会自动解析并生成配置文件。稍等片刻，你便能在列表中看到一组组节点。

  3. 选择节点
    点击“代理”（Proxies）标签，你会看到类似“香港01”、“台湾中华电信”、“澳门电讯”等命名清晰的节点。通常，选择延迟数值最低（绿色）的节点即可获得最佳体验。

第三步：设置分流规则——让B站“走对路”

Clash的精髓在于“分流”。我们需要确保：访问B站大陆版时直连，访问B站港澳台版时走代理。

  1. 开启规则模式
    在Clash主界面，将模式切换为“规则”（Rule）而非“全局”（Global）。这样，Clash会依据配置文件中的规则自动判断流量去向。

  2. 自定义规则（进阶操作）
    如果你对默认规则不满意，可以手动编辑配置文件。例如，添加以下规则：

  1. 启动系统代理
    在Clash主界面，打开“系统代理”（System Proxy）开关。此时，你的所有浏览器和应用程序流量都会经过Clash的智能调度。

第四章：避坑指南——你可能会遇到的“拦路虎”

1. 节点失效或速度慢

解决策略：定期更新订阅链接；在“代理”页面逐个测试节点延迟，剔除高延迟节点；考虑购买多个服务商的套餐以备不时之需。

2. B站提示“地区不支持”

原因分析：可能是分流规则未正确匹配，或B站检测到IP异常。
解决策略：清除浏览器缓存和Cookie；更换节点；在Clash中开启“TUN模式”（虚拟网卡模式），强制全局接管网络流量。

3. 弹幕功能异常

解决策略：港澳台专区的弹幕服务器与大陆不同，若弹幕加载失败，尝试在B站设置中切换弹幕服务器为“港澳台”选项。

4. 流量消耗过快

解决策略：在B站客户端中降低默认清晰度；关闭Clash的“日志记录”功能；仅在需要时开启代理，观影结束后及时关闭系统代理。

FAQ

SSR 的混淆插件有什么作用？
混淆插件用于伪装流量，使其看起来像普通的 HTTP 或 TLS 请求。常见类型有 plain、tls1.2_ticket_auth 等。合理设置混淆能有效降低被识别的风险，提升连接成功率。
SSR 混淆方式如何增强隐蔽性？
选择合适混淆方式，如 tls1.2_ticket_auth，可模拟 HTTPS 流量。合理搭配协议和混淆参数，提高节点稳定性和抗封锁能力，确保长期科学上网体验顺畅。
Trojan-go 如何启用 WebSocket 支持？
在配置文件中将 transport 参数设置为 websocket，并指定 path 路径。客户端需同步使用相同路径及主机名。这样可将 Trojan 流量伪装为普通 WebSocket 通信以提升隐蔽性。
Hysteria2 的拥塞控制算法是什么？
Hysteria2 基于 QUIC 协议，采用 BBR 拥塞控制算法。相比传统 TCP 机制，BBR 能更好地利用带宽资源，提高高延迟网络下的吞吐率和响应速度。
如何提高 Vmess 协议的安全性？
可通过启用 TLS 加密、使用安全端口（如 443）、结合 WebSocket 或 gRPC 传输方式来提升安全性。同时，避免公开分享 UUID，定期更换节点参数能进一步减少被封风险。
Mellow TUN 模式对系统全局流量的作用是什么？
TUN 模式拦截系统 IP 层的所有流量，实现全局代理效果。相比 SOCKS5 只作用于特定应用，TUN 能覆盖游戏、视频和浏览器流量，保证全系统科学上网体验稳定高效。
VLESS 的伪装流量如何提升隐蔽性？
VLESS 通过 Reality 或 XTLS 模式对流量进行伪装，使其在外观上与正常 HTTPS 请求一致。这样可以绕过深度包检测和封锁，提高高封锁网络环境下的可用性。
PassWall2 支持哪些内核？
PassWall2 支持多种代理内核，如 Xray、V2Ray、Sing-box、Trojan-go、Hysteria2 等。用户可在插件管理中切换所需内核，以获得不同协议与性能的支持。部分内核需手动下载并启用。
Nekoray 的订阅更新机制如何运作？
Nekoray 可以通过远程订阅 URL 自动下载最新节点和规则文件。用户可以设置更新频率，程序会定时检测并替换旧节点，保持配置最新状态。
Trojan 的证书配置错误会导致什么问题？
如果 TLS 证书无效或域名不匹配，Trojan 客户端将无法建立安全连接，导致节点无法使用。需要确保证书有效、域名正确，才能保证正常访问。
